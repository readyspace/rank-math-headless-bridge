# A short glossary

| Word | Plain meaning |
| --- | --- |
| SEO | Search engine optimization: information and choices that help search engines understand a page. It does not guarantee a ranking. |
| Headless WordPress | WordPress stores and edits content, while a separate app displays the public website. |
| CMS | Content management system. Here, that means WordPress. |
| Frontend | The public website visitors see. Here, that means Next.js. |
| API | A way for two programs to ask for and exchange information. |
| GraphQL / WPGraphQL | GraphQL lets an app ask for named pieces of data. WPGraphQL adds that API to WordPress. |
| REST | Another API style. An app asks a specific web address for information, such as SEO for a post ID. |
| Metadata | Data about a page, such as its search title and description. It often goes in the HTML rather than the visible article. |
| Canonical URL | The preferred address of a page. Search engines use it as a hint when similar pages have different addresses. |
| Robots / noindex | Instructions for search engines. `noindex` asks them not to list a page. It does not stop people from opening it. |
| Open Graph / Twitter tags | Information used to build previews when someone shares a link. |
| Schema / JSON-LD | Structured information about a page, such as its article type or author. JSON-LD is the format used by our examples. |
| Post ID | A number WordPress gives a post or page. It is different from the page's web address. |
| Origin | The first part of an address, such as `https://www.example.com`, without a page path. |
| Route / path | The part that identifies a page, such as `/news/hello/`. |
| Server rendering | Creating a page's HTML before sending it to the browser. Our examples put SEO into this HTML. |
| Cache | A saved copy used to avoid rebuilding the same result each time. It needs refreshing when the content changes. |
| Deploy | Put your built website on its hosting service so visitors can use it. |
| Staging | A test copy of a site, separate from the live website. |
| Alpha | An early version that still needs testing and feedback. |
| IndexNow | A way to tell participating search engines that a public page changed. It does not guarantee indexing. |
| GPL-3.0-or-later | The open-source license for this project. It allows use, changes and sharing, with rules for sharing source and keeping license notices. |

Start with the [setup guide](quick-start.md), then use this page when a term is unfamiliar.
